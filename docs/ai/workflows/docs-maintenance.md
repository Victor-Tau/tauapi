# Docs Maintenance

Route task meaning (including Chinese) and predicted paths, then read policy/domain/contracts.
Maintain one compact record for ordinary work. Expand for security, billing, schema and releases.
Inspect source/tests before changing behavior. Recompute impact from staged, unstaged, untracked,
deleted and renamed paths; combine baseline and candidate registry obligations.
For each affected contract record updated/reviewed_unchanged/not_applicable plus reason and evidence.
Update Chinese user effects; docs_impact none requires explanation. Generate indexes, run docs checks,
checker tests and technical profiles against actual candidate. Report failures/skips/blockers honestly.
Record local verification explicitly; GitHub Actions is intentionally not used. Only externally observed
candidate evidence establishes any remote verification. Archive conclusions
by date after validation; archival changes still get docs checks. Never put a future self-commit hash in a record.
