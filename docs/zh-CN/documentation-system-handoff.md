# 文档体系交付说明

已建立英文技术规范、中文使用说明、历史证据与不可变初始化参考四层文档体系。
[英文入口](../ai/INDEX.md)用于维护，[中文首页](README.md)用于了解和使用项目。
单一登记表生成任务索引，按中文需求与路径合并相关契约，并检查变更影响和文档处置。
原指导、设计包及迁移原文保留校验值；用户原有未跟踪文件保持原样。

## 日常使用

在仓库根目录运行：

```sh
make docs-setup
make docs-check docs-test
make docs-generate
make docs-impact-worktree DOCS_BASE=<基线版本>
```

需要实际执行影响选出的检查时，使用 `make docs-verify` 并指定 DOCS_BASE、DOCS_HEAD、DOCS_CHANGE。
修改实现时同步维护文档；未改变契约时填写具体理由和证据。新增文档先登记，任务索引由工具生成。
从组件目录启动 Claude 时，使用 `bash ../scripts/docs/claude-root.sh` 回到仓库根目录。
