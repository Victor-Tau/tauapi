# 登录与会话

登录凭据保存在浏览器内存和受保护的 Cookie 中。刷新页面会尝试恢复会话；多标签页会协调刷新。
网络临时故障可以重试。公开页面可能暂时显示为未登录，进入登录页或受保护页面后会重新确认。

可在安全设置中查看和撤销设备会话。修改密码或安全因素可能使其他设备退出。
个人访问令牌与 API Key 用途不同：前者按权限操作面板，后者调用模型中转接口。
个人访问令牌只在创建时显示一次，应按需授权和设置过期时间。

持续登录循环时，先检查网络、站点 HTTPS、代理与 Cookie 配置；不要把凭据复制到日志。
维护人员按[排障入口](../ai/TASK_INDEX.md)追踪前后端刷新流程。
